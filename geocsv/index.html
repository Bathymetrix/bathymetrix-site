MERMAID GeoCSV (testing only)

GeoCSV pairs a text table with comments describing its fields, units, and provenance. MERMAID GeoCSV records describe drifting hydrophone positions, measurements, and seismic waveform segments; the waveform samples are distributed separately.

The GeoCSV specification describes the format. mermaid-geocsv provides Python tools for fetching and reading MERMAID metadata, associating it with waveforms, and creating SAC station location headers for writing with ObsPy.

Reproducible access

Each production release will retain the exact upstream creation timestamp, a complete manifest, and checksums for every file. A Python download will select one release for the whole operation. A specific release can be requested again without relying on whichever release is latest.

Snapshot creation, scientific validation and publication are maintained by the separate mermaid-publisher project. Testing downloads use the isolated /geocsv/testing/ collection. Testing latest serves full-corpus schema 1.0.0-rc1 snapshot 2026-11-05T23:41:47.235000Z, readable by mermaid-geocsv 0.29.0 or newer. Older retained snapshots may have incompatible headers. Release paths use hyphens in place of creation-timestamp colons; literal identities remain unchanged in metadata.

For testing access, use:

from mermaid import geocsv

results = geocsv.fetch(
    "P0006",
    base_url="https://bathymetrix.com/geocsv/testing/",
    output_dir="downloads",
)
tables = geocsv.read(results)

For questions about metadata or publication, contact Bathymetrix.
