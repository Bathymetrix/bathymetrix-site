MERMAID GeoCSV

GeoCSV pairs a text table with comments describing its fields, units, and provenance. MERMAID GeoCSV records describe drifting hydrophone positions, measurements, and seismic waveform segments; the waveform samples are distributed separately.

The GeoCSV specification describes the format. mermaid-geocsv provides Python tools for fetching and reading MERMAID metadata, associating it with waveforms, and exporting located SAC files.

Publication status

All hosted GeoCSV data will be labeled testing only, including full-corpus download tests. A first production scientific release has not been authorized.

The initial testing batch is limited to MERMAIDs P0006 and P0045. Cite the MH network using DOI 10.7914/SN/MH.

These initial workflow tests may be removed after verification; permanent availability of testing downloads is not promised.

The production collection is being prepared. Production downloads are not yet available. Full archive validation, data licensing, and citation details must be completed before the first release.

Reproducible access

Each production release will retain the exact upstream creation timestamp, a complete manifest, and checksums for every file. A Python download will select one release for the whole operation. A specific release can be requested again without relying on whichever release is latest.

Snapshot creation, scientific validation and publication are maintained by the separate mermaid-publisher project. Test downloads will use the isolated /geocsv/testing/ collection.

Once production access is authorized and published, Python access will use:

from mermaid import geocsv

results = geocsv.fetch(
    "P0006",
    base_url="https://bathymetrix.com/geocsv/",
    output_dir="downloads",
)
tables = geocsv.read(results)
